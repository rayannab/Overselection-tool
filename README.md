# Overselection tool



## Getting started

### Step 1
After cloning the git repo, please download the yolo model via this link : 

**https://github.com/ultralytics/assets/releases/download/v8.2.0/yolov8x-seg.pt**

Once you download the .pt file, place it in your Overselection-tool folder. 

### Step 2

Install the requirements using the Requirements.txt

### Step 3

Run the command : .\build.bat , this will build the project and create a folder named 'dist/AnalyseOverselection', in which you will find your interface executable 'interface.exe'.
